Evidence that stays after the demo closes

Each run records its firmware hash, test method, expected values, observed checks, timings and before/after telemetry. JSON is machine-readable; HTML is printable and includes full evidence.

The latest 50 reports appear here. Older files remain in the project’s var/lab-reports folder. A run left “running” by a process crash is incomplete, never a pass.

KNOW WHAT THE TEST PROVES

Coverage of this hub’s configured components

All components used by the sensor acquisition and telemetry path have functional, configuration or diagnostic checks. Support-only and unused MCU peripherals are listed separately. Passing an emulator test does not validate physical wiring, voltage, oscillator accuracy or sensor calibration.
