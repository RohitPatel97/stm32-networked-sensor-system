# Source provenance

Created October 12, 2026 as a new independent project alongside both originals.

| Component | Original repository | Imported HEAD |
| --- | --- | --- |

The import copied tracked and non-ignored source files, excluding Git metadata,
virtual environments, and ignored build products. Both MIT licenses are retained.
[originals-manifest.json](originals-manifest.json) records SHA-256 hashes for all
116 imported original files. `scripts/check_originals.py` verifies that the
neighboring originals still match. The check is local provenance verification;
it is not required on a separate machine without those original checkouts.

Component WORKFLOW documents and older validation reports describe the original
repositories at the recorded commits. Their old publication links and previous
measurements are historical evidence, not publication/test claims for this new
combined project. Root README, protocol, and validation documents define the
current combined behavior.
