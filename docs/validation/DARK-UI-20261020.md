# Dark desktop UI validation — 2026-10-20

The desktop console now uses charcoal backgrounds, light text, larger small labels, and distinct blue/gold/purple acceleration axes. The native startup screen, title bar, WebView background, controls, status badges, and canvas chart follow the same dark palette.

Validation:

- `node --check demo/web/lab.js` passed.
- `scripts/build_desktop.ps1 -InstallShortcut` built the desktop executable successfully and refreshed the desktop shortcut.
- The rebuilt desktop app started Renode and passed its live firmware/sensor preflight.
- Visually checked the overview, component tests, report list, acceleration result, chart, and diagnostics in the native window.
- The acceleration demonstration passed with readings of `0.500 / -0.250 / 0.750 g` from ARM firmware. Evidence: `var/lab-reports/20261020T174838-8bd482be.json`.
- The nine selected text/background pairs in [contrast.json](dark-ui-20261020/contrast.json) measure at least 7:1. Main text measures 13.73:1 and secondary text 9.14:1. This is a palette check, not a complete accessibility audit.

Screenshots: [overview](dark-ui-20261020/overview.png), [acceleration](dark-ui-20261020/acceleration.png), [chart](dark-ui-20261020/chart.png).

The full firmware regression suite was not rerun for these presentation changes; the existing full-suite results are documented in [the acceleration demo validation](ACCELERATION-DEMO-20261020.md).
